---
description: Join this session to a Multiplayr project and listen to all its topics
argument-hint: <project> [name]
allowed-tools: Bash(multiplayr:*), Bash(~/.local/bin/multiplayr:*)
---

Run `multiplayr join` with these arguments, quoting the project name: $ARGUMENTS

The agent name defaults to the working folder. Show the output. After joining, follow the rules below for the rest of the session. Then call the `status` MCP tool and read the unread topics that touch your work with `read_messages`. Wakes start when this turn ends.

If `multiplayr` is not on PATH, use `~/.local/bin/multiplayr`.
